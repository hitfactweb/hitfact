# HITFACT — DEVELOPMENT ROADMAP

## Phase 0 — Planning

- finalize brand
- finalize product requirements
- choose hosting/providers
- create repository
- configure environments
- create database
- establish coding conventions

## Phase 1 — Core

- public homepage
- latest feed
- categories
- article/post pages
- authentication
- user profiles
- admin login
- CMS
- media upload
- publish/draft/schedule
- basic search

## Phase 2 — Social

- likes
- comments
- replies
- saves
- shares
- follows
- notifications
- reports
- moderation

## Phase 3 — Fact Check

- fact-check editor
- verdict system
- source management
- fact-check archive
- filters
- correction history

## Phase 4 — Interactive

- polls
- results
- quizzes
- scoring
- forms
- surveys
- response analytics
- exports

## Phase 5 — Advanced

- trending
- recommendations
- advanced analytics
- background jobs
- dedicated search
- advanced moderation
- editorial collaboration
- richer notifications

## Launch checklist

- domain/SSL
- production environment
- database backup
- storage backup
- email
- error monitoring
- analytics
- sitemap
- robots
- privacy/terms
- admin 2FA
- rate limiting
- moderation policy
- correction policy
- test critical flows
- mobile QA
- desktop QA

## Golden rule

Do not sacrifice security, correctness or editorial credibility to
launch faster.
