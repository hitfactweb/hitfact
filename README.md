# HITFACT — Master Project Documentation

## Project

HITFACT is an independent digital media platform focused on politics,
media, fact-checking, explainers, public-interest content, polls,
quizzes and community interaction.

### Brand

- Name: HITFACT
- Tagline: FACTS THAT HIT.
- Positioning: Politics • Media • Reality
- Editorial principle: Follow evidence, not political affiliation.

## Product vision

A social-first media website combining: 1. Instagram-like latest-first
feed 2. User accounts and profiles 3. Likes, comments, replies, saves
and sharing 4. News/articles 5. Fact-checking with evidence and verdicts
6. Polls, quizzes, surveys and custom forms 7. Admin CMS and editorial
workflow 8. Moderation, reporting and user management 9. Search,
categories, tags and fact-check database 10. Analytics, notifications,
SEO and scalable infrastructure

## Development rule

Do not build everything as one giant first release. Build the core
architecture correctly, then enable modules in phases. Every major
feature must be production-ready, permission-aware, mobile responsive
and documented.
