# HITFACT — UI/UX SPECIFICATION

## Design language

Editorial + social + modern.

Colors: - \#ED1C24 - \#0A0A0A - \#FFFFFF - neutral grays

Typography: - bold display font for headlines - clean sans-serif for
body

## Desktop homepage

Header - logo - Home - Explore - Fact Check - Polls - Quizzes - Search -
Account

Main: - latest feed - sidebar for trending and interactive content

## Mobile homepage

Top: - HITFACT - search/account

Feed: - full-width post cards - sticky/compact category navigation

Bottom: Home \| Explore \| Create/optional \| Notifications \| Profile

## Post card

- source/avatar
- time
- category
- title
- media
- caption
- verdict badge if fact-check
- like/comment/save/share

## Article page

Headline Summary Author/date Featured media Body Sources Related content
Comments

## Fact-check page

Claim Claimant Verdict Context Evidence Analysis Sources Related claims
Correction history

## Poll UI

Question Options Vote Result state Participation count if public

## Quiz UI

Progress Question Options Next Submit Score/result Explanation

## Form UI

Progress if multi-step Fields Validation Consent Submit Confirmation

## Admin

Desktop-first responsive dashboard with: - sidebar - top bar - cards -
tables - filters - modals/drawers - editor - analytics charts

## Accessibility

Keyboard support, focus states, labels, alt text, contrast, reduced
motion.

## Responsive breakpoints

Use framework defaults and test: - small mobile - large mobile -
tablet - laptop - large desktop
